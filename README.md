# КМ2 — Распознавание персональных данных

[Отчёт](report.pdf) · [Ноутбук](km2.ipynb) · [Google Colab](https://colab.research.google.com/github/Champ1y/km2-pii-recognition/blob/main/km2.ipynb) · [Полный проект с моделью](https://github.com/Champ1y/km2-pii-recognition/releases/download/km2/km2_variant12.zip)

Гибридный распознаватель объединяет дообученный RuBERT для имён и фамилий с алгоритмическими правилами для ИНН, паспорта, банковской карты, ОГРНИП, IP, e-mail, свидетельства о рождении и кода КЛАДР. Для ИНН, ОГРНИП и карт проверяются контрольные разряды.

Основа набора данных — factRuEval2016, дополненный размеченными текстами с недостающими атрибутами. Схема разметки — BIO. Выборки train/validation/test содержат 977/169/420 текстов.

| Метрика по BIO-классам | F1 |
|---|---:|
| Средневзвешенная | 0,9843 |
| Средняя | 0,9306 |

Precision, recall и F1 по каждому атрибуту представлены в [таблице](recognition_per_attribute.csv), полный расчёт — в [recognition.json](recognition.json).

`km2.ipynb` содержит открытый код подготовки данных, распознавания и оценки. Готовая модель загружается из Releases автоматически при её отсутствии. Повторное обучение по умолчанию отключено.

`km2_source.zip` содержит исходные модули, скрипты, данные, тесты и результаты без больших весов. Полный архив `km2_variant12.zip` в Releases включает обученную модель и отчёт.
